Run node verify-frozen.mjs to check file hashes and rerun controlled authored candidate checks without API calls or project dependencies. Generated suites in evidence/ are stored as text and are NOT executed. No API keys, provider configuration, workspace IDs, or private employer data are included.

Only a selected model-input file may be sent to a reviewer; never send this directory wholesale, labels, checks, prior chat, or the evidence files except as a declared evidence condition. No current-version execution logs for those evidence suites are supplied. Older version 2 logs must not be attached to these version 5 candidates.

This is versioned and tamper-evident under its manifest, not write-protected or authenticated storage. Checksums detect accidental changes; they do not prevent someone replacing both data and manifest.
